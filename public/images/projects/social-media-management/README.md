# Social Media Management Project Images

Upload your Social Media Management project images into this folder:
`public/images/projects/social-media-management/`

### Image File Naming:
- `smm-1.jpg` (or `.png` / `.webp`) -> Savanna Digital Campaign
- `smm-2.jpg` (or `.png` / `.webp`) -> Sonic Waves Social Media Asset Pack

### Editing Projects & Image Paths:
You can edit or add new project items and image filenames in:
`content/projects/social-media-management.json`
