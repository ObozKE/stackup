# Brand Design Project Images

Upload your Brand Design project images into this folder:
`public/images/projects/brand-design/`

### Image File Naming:
- `brand-design-1.jpg` (or `.png` / `.webp`) -> Kazi Workspace Brand Identity
- `brand-design-2.jpg` (or `.png` / `.webp`) -> Urban Beats Festival Identity

### Editing Projects & Image Paths:
You can edit or add new project items and image filenames in:
`content/projects/brand-design.json`
